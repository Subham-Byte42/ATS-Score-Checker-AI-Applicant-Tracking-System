# 🥇 AI Resume Analyzer (ATS Score Checker)

> An AI-powered web application that analyzes resumes, calculates an ATS compatibility score, and provides personalized suggestions to help job seekers improve their resumes before applying for jobs.


[🌐 Live Website](https://ats-score-checker-615076846565.asia-southeast1.run.app) 


---

## 📖 Overview

Recruiters often receive hundreds of resumes for a single job opening. To simplify the hiring process, many companies use **Applicant Tracking Systems (ATS)** to automatically filter resumes before a recruiter even sees them.

This project was built to help job seekers understand how ATS systems evaluate resumes. Users can upload their resume, receive an AI-generated ATS score, identify missing keywords or skills, and get practical suggestions for improvement.

The goal isn't just to assign a score—it's to explain *why* the score was given and help users build stronger resumes.

# ⚙️ How It Works

1. Create an account.
2. Verify your email.
3. Login securely.
4. Upload your resume.
5. Resume text is extracted.
6. AI analyzes the resume.
7. ATS score is generated.
8. Suggestions are displayed.
9. Improve your resume and analyze again.
